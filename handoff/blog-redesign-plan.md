# 个人博客改版计划

双排书架及蝴蝶转场已在本地打样。[博客内容维护计划](blog-content-plan.md)记录接下来的文章录入、详情页和发布设计。目标是在 `VibeCoding-web` 保留个人介绍作为首访开场，用蝴蝶转场进入博客首页，再通过书架浏览生活记录和做过的项目。卡片可以点进详情。

## 范围与待定事项

- **已明确**：保留现有的滚动开场、肖像和个人介绍。首访第一次下滑时，肖像随滚动从下方缓慢升起并亮起来。肖像完整出现后再继续下滑，蝶群从右下角飞出，缓慢掠过画面并过渡到博客。移除首页的机器人竞赛、职业探索 Agent 和 Java 论坛展示段落。博客以卡片组合分别浏览生活记录和做过的项目，卡片可点进详情。
- **书架方案**：生活记录和做过的项目各占一排，通过右侧按钮或竖向滚动换排。真实内容接入后，建议默认展开最近一条生活记录。点书脊把卡片移到中央，点中央封面或「查看详情」进入对应页面。每篇详情有独立链接，返回时恢复之前的分类和卡片。
- **设计阶段待定**：首批公开内容和封面、蝶群的画风与疏密、首访的记忆范围及回访体验、桌面和手机的书架构图。参考图提供了书脊、封面转动和纸张展开的设计，站点文案及视觉素材使用自己的内容。
- **改版范围**：首页展示段落的移除与独立页面、旧链接的处理分开确认。学习区和旧版主页的删改需要另行确定。

## 任务拆分

### 1. 确认页面流与视觉分镜

- 在同一份分镜里标出初始滚动提示、肖像显现过程、肖像完整亮起、蝴蝶飞行中段、博客落点、书架选中态和详情展开态。补一版手机构图，确认触摸和点击入口。
- 确定回访默认落点、「进入博客」入口和「关于我」是否可回看介绍。建议首访通过首页看序幕，文章直达链接直接打开正文。
- **验收**：每个关键画面能说明访客看到什么、可以做什么、下一步去哪里。首访和回访的规则有明确文字。

### 2. 准备首批内容与卡片素材

- 为两组内容各选一条可以公开的记录做首批样例。生活记录准备标题、日期、摘要、正文和可公开照片。项目准备标题、简介、截图和可公开链接，个人贡献以确认过的事实为准。
- 为每条内容确定短书脊名、完整标题、封面和详情页地址。检查中文标题在窄书脊与中央封面下方的可读性。缺封面时用排版代替，避免为凑满书架补写不存在的经历。
- **验收**：两类内容均可用真实样例检查布局。图片与文案经过公开范围检查，书脊和详情标题可一一对应。

### 3. 搭建博客首页、详情页与返回路径

- 建立「生活记录 / 做过的项目」浏览入口和可点击的卡片。两类内容共用卡片结构，详情按内容呈现长文、照片、项目截图或演示链接。
- 让每篇详情可通过独立地址访问和刷新。实现返回书架、恢复分类与卡片位置，再接入参考里的纸张展开效果。
- **验收**：两类卡片都能打开对应详情。直接打开链接能读到内容，返回能继续浏览原卡片，移动端正文可正常纵向滚动。

### 4. 制作书架与选卡动效

- 实现立体书脊和封面。选中项滑到中央、转出封面，原选中项收回去。中央封面下方显示完整标题、日期和摘要。
- 桌面支持点击书脊、左右箭头和键盘操作。手机支持横滑和点选。内容少时按实际条目排布，书架始终显示可打开详情的入口。
- **验收**：分类切换、连续选卡、打开详情及返回后的状态一致。纵向滚动保持原有方向，移动端可清楚区分横滑浏览与纵向阅读。

### 5. 重组肖像开场与蝴蝶转场

- 保留首页现有的下滑提示、肖像从下方升起、聚光灯渐亮及个人介绍。沿用 `homepage/scrollScenes.js` 中的肖像显现节奏，在肖像完整展示之后接入蝴蝶与书架。移除首页的机器人竞赛、Agent 和论坛展示段落。相关内容按第二项整理后可作为项目卡片进入博客。
- 按分镜实现蝶群从右下角错落飞入、掠过画面并散开，同时从深色肖像过渡到浅色书架。为「进入博客」和减少动态效果设置直达书架的路径。
- **验收**：首访先看到滚动提示，下滑时肖像缓慢升起并亮相，介绍完整可读，继续下滑才出现蝶群。回滚到肖像段时保留原有的反向变化。快速滑动、触摸、点击进入和减少动态效果设置下均能正常访问博客内容。

### 6. 联调、构建与发布准备

- 在桌面和手机尺寸分别走查首访、回访、分类切换、选卡、详情直达及返回。检查键盘操作、文字可读性和转场表现。
- 按现有流程构建静态产物，使用 `docs/` 本地服务核验 GitHub Pages 路径与资源链接。记录每个通过验收的阶段并分别提交。发布后核对首页、代表性的详情链接和既有入口。
- **验收**：构建通过，主要路径可在本地验证。实际发布后再记录线上验证结果。

## 推荐推进顺序

先做任务 1，确认画面和交互，再做任务 2 至 3，用真实内容先打通浏览与阅读。书架动效和蝴蝶转场可在博客落点与卡片尺寸明确后分别制作，再合并联调。每个阶段以对应的验收项为完成条件。

当前书架原型在 `codex/blog-two-row-bookshelf`。后续文章接入继续在本地预览，验收后再把博客静态产物放进发布用的 `main/docs/blog/`。
