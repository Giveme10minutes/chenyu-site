# 从五人合照进入书架

开场最后一幕以五人合照和「专业团队 为你服务」收尾。转场要让这句台词有时间落下，再把访客带到可以操作的书架。

| 方案 | 画面 | 适用与取舍 |
| --- | --- | --- |
| 黑底合照上移 | 合照和台词随整张黑底画面上移，暖白书架从底部逐渐露出。交界处留一点阴影，书架内容轻微上移到位。 | 动作沿着下滑方向展开，给合照明确的退场。第一版在 `codex/blog-poster-reveal` 实现。 |
| 合照收成一张照片 | 合照从全屏缩成带纸边和阴影的照片，落到暖白背景，再带出书架。 | 像把刚看过的合照收进相册，与摄影兴趣呼应。需要先确定照片落点与书架的空间关系。 |
| 关灯再开灯 | 合照灯光收暗，停一拍，暖光照亮书架。 | 呼应开场打光，动作简洁。黑场时长决定用户是否会误以为页面停住。 |
| 蝴蝶转场 | 蝶群分两波从右下角铺开，暖白背景和书架随之出现。前景快速掠过时略有模糊。 | 画面热闹，合照之后会再出现一个视觉高潮。停滚时蝶群位置停下，翅膀仍在扇动。已存档，可独立预览。 |

## 蝴蝶版存档

标签为 `archive/blog-butterfly-transition-2026-11-16`，对应提交 `c64aa51`。标签包含完整源码、素材和已构建的博客页面，原开发分支 `codex/blog-two-row-bookshelf` 也留在该版本。

如需并排对照，在仓库根目录为存档建立一个独立工作目录。直接用存档自带的静态页面即可预览。

```sh
git worktree add --detach ../VibeCoding-web-butterfly archive/blog-butterfly-transition-2026-11-16
python3 -m http.server 8766 --bind 127.0.0.1 --directory ../VibeCoding-web-butterfly/docs
```

浏览器打开 [蝴蝶版介绍页](http://127.0.0.1:8766/blog/intro/)。

## 黑底上移版的检查点

合照完整出现后停留一段滚动距离。上移过程可随滚动暂停和反向返回。书架露全即可操作，继续滚动可正常换排。启用减少动态效果或关闭 JavaScript 时，可依次浏览介绍并使用书架入口。
