# 博客书架动效规格

本规格对应 [个人博客改版计划](blog-redesign-plan.md)中的书架与详情。视觉参考是 Leon Vasari VHS 书架录屏及随附提示词。以下数值是本站打样起点，实际手感以桌面和手机预览为准。

## 双排原型 · 2026-11-16

- 上排为「生活记录」，下排为「做过的项目」。每次完整显示一排，另一排在屏幕的上缘或下缘露出一截。右侧同一个按钮切换上下排，桌面滚轮和手机竖滑也能换排。两排分别保留选中的书。
- `/blog/intro/` 提供介绍和蝴蝶动画，`/blog/` 提供书架。蝶群退场时保留已经显示的书架画面，在同一文档内更新地址。书架滚到上排即到顶，左上角和浏览器历史提供返回介绍的路径。
- 首版使用三项已公开的个人兴趣和三个已有项目验证排布。每排默认打开中间一本。书籍详情沿用下文的后续计划。

## 画面衔接

沿现有首页下滑，肖像亮相后蝶群从右下方飞入。暖白纸面铺开时，书架连同分类和当前封面逐渐出现。书架出现时已经有一本书正对访客，开场无需自动翻动书架。尚未显现的书架控件不接收焦点或点击，露出后可直接操作。蝴蝶退场后，纵向滚动在两排之间切换，横向浏览从当前排的书架范围内开始。

## 书架构图与卡片

- 暖白纸面上方居中显示当前分类，右侧按钮指向另一排。书架横贯可用宽度，中央展示选中封面，两侧按实际条目排列书脊。
- 书脊和封面是同一个有厚度的盒子的两个面。相邻的书脊保持紧密间距。中央封面转出时略微靠前、抬高并轻倾，投下柔和阴影。封面两侧的卡片同步让出空间。
- 中央封面下方显示完整标题、日期和「查看详情」。有摘要时显示一句。书脊优先使用短标题。真实照片和项目截图用作封面，缺图可用文字封面。所有分类共用同一套盒型和交互。
- 初始选中最近一条生活记录。首次切到项目时选中最近一个项目，切回时恢复该分类上次的选中项。单条内容直接展示封面，空分类显示简短空状态。书架两端按实际条目停止。

## 选卡动作

| 状态 | 画面 | 操作结果 |
| --- | --- | --- |
| 静止 | 中央封面完整可见，两侧是书脊 | 点两侧书脊选中，点中央封面进入详情 |
| 指针悬停 | 桌面端书脊缓慢起步，约 340 毫秒抬起 5 像素，向前略探并露一点封面。中央书只轻抬并前倾 | 指针移开时顺势归位。停在原书脊边缘仍可点击，触屏沿用点选和拖动 |
| 切换中 | 整排横移，原封面逐步收回，新封面逐步转出 | 连续操作以最后一次选中的目标为准 |
| 停稳 | 新书居中，标题和日期与新书一致 | 可再次选卡或打开详情 |

点击相隔多本的书脊时，书架沿途滑过中间卡片。封面打开程度由卡片距中央的位置连续决定，经过中央的卡片可以短暂露面。完整标题在确认选中项后更新，可沿移动方向做一次短距离遮罩滑入。切换过程中禁止从尚未对正的封面误开详情。

桌面可点书脊或用键盘方向键换书，键盘快捷键只在书架内生效。手机在书架上左右拖动，松手后吸附到最近的一项。以主要手势方向区分横拖和竖滑，拖动结束不触发卡片点击。窄屏保留中央封面，并尽可能露出相邻书脊。标题可换行，不压到书架。

### 几何和时间起点

| 参数 | 起点 | 对应效果 |
| --- | --- | --- |
| 卡片高度 | 桌面约 36–46% 的可见屏高 | 书架为视觉中心，上下保留分类与信息空间 |
| 书脊宽和封面宽 | 分别约为卡片高度的 17% 和 53% | 保留 VHS 盒的厚度比例 |
| 中央封面姿态 | 转面约 90°，滚转约 4°，向前移约卡高的 20% | 选中项有被抽出来的感觉 |
| 相邻项切换 | 约 350–500 毫秒 | 横移、转面和邻卡让位一同完成 |
| 标题出入 | 约 180–260 毫秒 | 完整标题沿切换方向更新一次 |
| 展开详情 | 约 450–600 毫秒 | 纸面从封面扩大至全屏 |
| 返回书架 | 约 300–450 毫秒 | 对应封面可见时，纸面收回原位 |

选中范围可先按相邻卡片间距计算。离中央不足一张卡片间距时，旋转、抬高、前移和阴影逐渐增强，超过一张间距时保持书脊姿态。连续切换从当前显示位置继续过渡，避免重新起步或跳帧。

## 从封面展开详情

1. 在书架停稳后，点击中央封面或「查看详情」。记录分类、卡片标识和书架滚动位置，同时记下封面在屏幕上的实际边界。
2. 暖白纸面从当前封面的尺寸和位置开始，带着封面原有的轻微倾斜向外展开，最后覆盖视口并恢复水平。标题、封面和摘要随纸面显现，正文随后可以纵向阅读。可先用纸面裁切和文字位移做出完整过程。
3. 每条内容有独立的静态详情地址，例如 `/blog/entries/某条记录/`。直接打开或刷新详情地址时，直接显示正文。桌面首屏可左文右图，手机将标题、封面与正文排成单列。
4. 点「返回书架」或使用浏览器后退，回到原分类、原卡片和书架位置，键盘焦点落回对应封面。封面可测量时，返回动效朝它收回。直接从外部访问详情的人使用「返回书架」时落在该条目的分类，并选中对应卡片。
5. 用户启用减少动态效果时，书架立即切换，详情直接显示。点击、键盘和直接链接依然可用。

卡片数据至少有稳定标识、分类、完整标题、书脊短标题、日期、详情路径。封面图与摘要可选。分类、卡片标识和返回位置可以随浏览历史记录保存，保证刷新直达与后退回位的行为可分别验证。

## 参考样例与本站取舍

样例通过无限书架、鼠标圆环和墨水晕染强化录像带陈列感。本站第一版优先验证中央封面翻出、纸面展开、详情直达和返回回位。录屏中的年代筛选对应本站的两个内容分类，封面素材从个人记录与项目资料中准备。循环书架、鼠标圆环、墨水晕染作为可单独评审的后续效果。

## 验收清单

- [ ] 慢速下滑和快速下滑都能从蝶群到达有默认封面的书架。转场结束前往回滑可回到肖像。进入书架后，通过返回链接或浏览器历史回到介绍。
- [ ] 点任意侧边书脊时，整排横移，旧封面收回，新封面转出，邻卡自然让位。
- [ ] 快速连点、跨多张切换和切换分类后，中央封面、标题、日期及详情链接对应同一条内容。
- [ ] 手机横滑能换卡，竖滑能滚页面，松开拖动不会误开详情。
- [ ] 点击中央封面时纸面从该封面的位置展开。详情直达与刷新均显示同一条内容。
- [ ] 返回按钮和浏览器后退恢复分类、卡片、滚动位置及可操作焦点。
- [ ] 单条、空分类、长中文标题、窄手机和减少动态效果设置下均可正常浏览。
